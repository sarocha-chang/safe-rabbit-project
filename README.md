# Safe Rabbits Project 🐰
A rabbit adoption and rescue platform inspired by rabbit cafés that help rabbits find safe homes.

## Features
- Rabbit adoption listings
- Adopted rabbits archive
- Café staff rabbits
- Filtering & search
- Rabbit detail pages

## Tech Stack
- Next.js
- TypeScript
- Firebase Firestore
- Firebase Storage
- Tailwind CSS
